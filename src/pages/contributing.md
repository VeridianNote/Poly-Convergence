# Contributing

We welcome contributions from community members. All content is submitted through GitHub pull requests and reviewed before publishing.

For detailed instructions — including markdown formatting, image handling, privacy guidelines, and content standards — see the full [CONTRIBUTING.md](https://github.com/VeridianNote/Poly-Convergence/blob/main/CONTRIBUTING.md) on GitHub.

## Quick Start

1. Fork the [repository](https://github.com/VeridianNote/Poly-Convergence) on GitHub
2. Create a new branch for your contribution
3. Add or edit content in the `docs/` or `blog/` directories
4. Submit a pull request

## Content Types

- **Blog posts** (`blog/`) — Articles examining specific claims, providing analysis, or discussing current topics
- **Wiki pages** (`docs/`) — Educational reference content organized by category
- **Community stories** (`docs/community-stories/`) — First-hand accounts from community members

## Key Guidelines

- All claims should be sourced where possible
- Strip EXIF data from all images before submitting
- Do not include personally identifying information — yours or anyone else's
- Be factual. No personal attacks.
- By submitting a PR, you agree to license your contribution under [CC BY-NC-SA 4.0](/content-license)
