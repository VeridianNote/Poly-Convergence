# Welcome to the Wiki

This wiki is a community-maintained knowledge base covering relationship advice topics. It's organized into the following sections:

- **Foundational Concepts** — Key ideas and frameworks for understanding healthy relationships
- **Common Myths** — Widely repeated claims examined against available evidence
- **Research & Sources** — Academic studies, expert perspectives, and reference material
- **Community Stories** — First-hand experiences shared by community members

## How to Use This Wiki

Browse the sidebar to explore topics by category. Each page aims to present documented facts, cite sources where available, and distinguish between evidence-based conclusions and personal experience.

## Contributing

This wiki is open to community contributions. If you'd like to add a page or improve an existing one, see the [Contributing guide](/contributing) for instructions on submitting a pull request.
