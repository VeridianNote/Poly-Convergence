# Poly Convergence

Community-driven education and accountability in relationship advice.

**[PolyConvergence.com](https://polyconvergence.com)**

## Contributing

We welcome contributions from anyone. See [CONTRIBUTING.md](CONTRIBUTING.md) for the full guide, but here's the short version:

1. **Fork** this repo and clone it locally
2. **Create a branch** for your changes
3. **Add content** to `blog/` (articles) or `docs/` (wiki pages)
4. **Submit a pull request** — we'll review it before it goes live

Content standards: be factual, cite sources, no personal attacks, no identifying information. By submitting a PR you agree to license your contribution under [CC BY-NC-SA 4.0](License.md).

## Running Locally

### Prerequisites

- [Node.js](https://nodejs.org/) v20 or later

### Quick Start

Install dependencies (first time only):

```bash
npm install
```

Then start the dev server:

```bash
npm start
```

The site will open at `http://localhost:3000`.

### One-Click Build

- **Windows** — double-click `run.bat`
- **Mac / Linux** — run `./run.sh`

Both scripts build the site and serve it locally so you can preview the result.

## Deployment

The site deploys automatically to GitHub Pages when changes are pushed to `main`. No manual steps needed.
