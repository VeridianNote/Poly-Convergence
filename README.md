# Poly Convergence

Community-driven education and accountability in relationship advice.

## About

Poly Convergence is a site dedicated to examining relationship advice claims with evidence and community experiences. See the [About page](https://veridiannote.github.io/Poly-Convergence/about) for more.

## Development

### Prerequisites

- [Node.js](https://nodejs.org/) v20 or later

### Local Development

```bash
npm install
npm start
```

This starts a local dev server at `http://localhost:3000/Poly-Convergence/`.

### Build

```bash
npm run build
```

### Deployment

The site deploys automatically to GitHub Pages when changes are pushed to `main`.
